The Leftovers Band: a single original dad joke for the make.fun "Dad Joke Showdown" bounty. `main.ts` writes one 112-character joke to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> I started a band called The Leftovers. We only play covers — cold ones — and we always reheat our greatest hits.

## Run it

```sh
node main.ts
```
